《基于大模型的个性化资源生成与学习多智能体系统》使用说明（Windows版）


【重要提示】
本项目是前后端分离的 Web 应用，须在 Windows 系统上运行。
请严格按照下面“执行位置”一栏的说明，在正确的文件夹路径下输入命令。


一、环境要求
1. Python 3.9 或更高版本
   （检查方法：打开 cmd，输入 python --version）

2. Node.js 18 或更高版本（含 npm）
   （检查方法：打开 cmd，输入 node -v 和 npm -v）
【注意】如果环境未配置，无法正常运行

============================================================
二、首次运行【只需执行一次，安装依赖】
============================================================

【第一步】安装后端依赖（Python包）
 执行位置：项目根目...\A3-learningSystem\                                   
 （即包含 backend、frontend、data 这三个文件夹的目录）      

操作：
  1. 进入 A3-learningSystem 文件夹（在文件管理器里双击进入）
  2. 在此目录打开 cmd（在地址栏输入 cmd 然后回车）
  3. 输入并执行以下命令后回车：
     pip install -r requirements.txt


【第二步】安装前端依赖（Node包）

 执行位置：项目根目录下的 frontend 文件夹                   
 完整路径示例：...\A3-learningSystem\frontend            

操作：
  1. 进入 frontend 文件夹（在文件管理器里双击进入）
  2. 在地址栏输入 cmd 然后回车
  3. 输入并执行以下命令：
     npm install

【第三步】
双击项目根目录(A3-learningSystem\ )下的【start.bat】文件


============================================================
三、日常启动（第二次及以后，只用一步）
============================================================

操作：
  1. 双击项目根目录下的【start.bat】文件
  2. 屏幕上会出现黑色命令行窗口，显示启动日志
  3. 等待约几秒，浏览器会自动打开系统页面
  4. 如果浏览器没有自动弹出，请手动打开浏览器访问：
     http://localhost:5173

     
============================================================
四、用户手册
============================================================

系统启动后，浏览器会打开主界面，您可以通过以下操作验证核心功能：

1. 登录界面：输入任意用户ID（如 u001），点击“登录”
2. 左侧聊天框：输入“我想学习内存管理”，点击发送，等待系统回复并更新右侧资源
3. 学习路径：点击界面中部的路径图节点，可切换知识点并查看对应推荐资源
4. 资源推荐：根据用户画像和当前进度推荐的资源，登录或进行操作后须等待几秒，资源推荐拉取更新
5. 生成资源：点击“生成资源”按钮，选择资源类型，查看生成内容
6. 答题反馈：在习题区域作答并提交，系统会自动更新画像和下一步路径
【注意】如果路径和资源推荐未立即响应，并非bug，而是后端大模型正在生成


五、注意事项与常见问题

【注意】如果登录后前端无数据，检【第一步】【第二步】

Q1：双击 start.bat 后闪退，什么都没有？
A1：请确保已经完成了“第二步：首次运行”中的依赖安装。


Q2：浏览器显示“无法访问此网站”？
A2：可能是端口被占用。
    1. 检查是否已经打开了其他前后端服务
    2. 关闭当前 cmd 窗口，重新双击 start.bat

Q3：后端启动报错“ModuleNotFoundError”？
A3：说明后端依赖没装全。
    回到项目根目录，重新执行：
    pip install -r requirements.txt

Q4：前端启动报错“command not found”或“‘npm’ 不是内部或外部命令”？
A4：说明 Node.js 未安装或未添加到系统环境变量。
    请安装 Node.js 并重启电脑后再试。

Q5：想停止服务怎么操作？
A5：直接关闭启动时弹出来的 cmd 黑色窗口即可。
